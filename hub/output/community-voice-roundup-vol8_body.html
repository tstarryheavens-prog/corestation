7. 全体像の整理：PoDE・RandomY・CoreID・Ping・MoneyX はどうつながるのか？

X（fxtwitter）や YouTube の最新トピックを追っていると、「CorePulse」「CorePass」「CoreStarter」「Ping Exchange」「MoneyX」「Luna Mesh」など多くの固有名詞が同時に出てきます。初めて Core Blockchain（XCB）に触れる方や、マイニングだけ回していて周辺サービスのつながりを整理したい方向けに、それぞれの役割と相互関係を1枚の設計図として整理しておきます。

  • 基盤レイヤー（Core Blockchain / RandomY・PoDE）：すべての取引やスマートコントラクト、認証ログが記録されるL1ブロックチェーンです。コンセンサスには計算資源の総量だけでなく電力効率・分散性を重視する PoDE（Proof-of-Distributed-Efficiency） と CPU 向けの RandomY を採用しており、ここに CoreStarter（PCノード・採掘）や CorePulse（Android採掘）が直接つながります。ネイティブ通貨は XCB（Core Coin） で、取引手数料やネットワークセキュリティの基盤を担います。
  • アイデンティティ・認証レイヤー（CorePass / CoreID / CorePass Connector / KYB）：個人や法人の本人確認（KYC / KYB）を中央集権サーバーに個人情報コピーを預けずに証明できる分散ID基盤です。CorePass Connector（OAuth 2.0対応）を経由することで、Ingrid氏の「Core資産ダッシュボード」のような外部Webアプリや、Ping Exchange の法人取引アカウントへ「パスワードなし・QRスキャン1回」で安全にログイン・権限連携ができます。ここで利用者がデータ提供の対価やユーティリティとして扱うのが CTN（Core Token） です。
  • 金融・決済・取引レイヤー（Ping Exchange / MoneyX・STC1 / Swaptopia / Wall Money）：XCB や CTN、さらに STC1規格の法定通貨連動トークン（USDX / EURX 等）が実際に流通・交換されるレイヤーです。取引所の仲介を最小化する直接取引型の Ping Exchange に加え、企業向けの法人取引（Core Chronicle #16）や、自己管理型バンキングを目指す Wall Money（信頼性優先で一般公開は延期・検証継続中）、分散型取引所 Swaptopia がこの層を構成します。
  • 通信・エッジ拡張レイヤー（Luna Mesh）：今回の X 投稿（@majiryokutya 氏など）でも期待が寄せられていた、インターネットや既存キャリア回線に依存しにくい分散型メッシュ通信構想です。ノードやモバイル端末が広がるほど、決済やID認証をオフライン・局所ネットワークに近い環境でも維持しやすくなります。

8. よくある質問（FAQ）：2026年11月時点の疑問をまとめて解消

Q1. スマホ（CorePulse）や古いPC（CoreStarter）で今から XCB を掘る意味はありますか？
A. 収益単価だけで見れば専用構成の高性能CPU（Ryzen 9 7950X 等）に比べハッシュレートは控えめですが、CorePulse は 50℃温度停止・バッテリー20%停止の保護があり、古いAndroid端末の遊休時間を活かして「取引所を経由せず最初の XCB を手に入れる」「ネットワークのノード・アドレス分散に貢献する」という点に実用的な価値があります。

Q2. YouTube や X で見かける「CORE（Core DAO）」と「XCB（Core Blockchain）」は同じですか？
A. まったく別のプロジェクトです。 YouTube 検索では BTCFi 系 EVM チェーンの「Core DAO（ティッカー: CORE）」が多くヒットしますが、本記事で扱っているのは Core Blockchain（ティッカー: XCB / CTN、CoDeTech・CorePass・Ping Exchange・PoDE/RandomY） です。ウォレットアドレスも XCB は cb から始まる ICAN 形式を使うため、送金や設定の際は必ずティッカーとアドレス形式を確認してください。

Q3. CorePass 1.72.78 の KYB や Ping Exchange の法人取引は一般ユーザーにも関係ありますか？
A. 直接法人アカウントを開設しない個人ユーザーにとっても無関係ではありません。個人事業主（Sole-owner）向けの KYB 簡素化が進んだほか、Ingrid 氏の資産ダッシュボードのように「CorePass の QR ログインだけで使える外部サービス」が増える土台になるため、パスワード管理や個人情報流出リスクを減らす恩恵が個人の使い勝手にも直結します。
