🚀 【完全攻略】Windows WSL2 で CoreMiner を絶対に導入する手順マニュアル

Windows PCのグラフィックや日常作業をそのままに、WSL2（Linux仮想化）を使ってLinuxネイティブの最高ハッシュレート（RandomY / PoDE）を引き出すセットアップ手順です。
このページの手順通りにコマンドをコピー＆ペーストするだけで、誰でも確実にマイニングを開始できます。

⚠️

【最重要】CoreMiner最新版は「Ubuntu 24.04 LTS 以上」が必須です！

Catch That Rabbit公式の最新版CoreMiner（v0.19.89 等）は、最新のC++20規格および最新の標準ライブラリ（GLIBC 2.38以上）でビルドされています。
従来の Ubuntu 20.04 や 22.04 LTS では、起動時に「/lib/x86_64-linux-gnu/libc.so.6: version 'GLIBC_2.38' not found」というエラーが発生し、絶対に動作しません。

💡 解決策はシンプル！
単に wsl --install と打つと古いUbuntuが入る場合があるため、本マニュアルのSTEP 1に記載の通り、必ず wsl --install -d Ubuntu-24.04 と明示指定してインストールしてください！

🖥️ 導入前の事前準備・システム要件チェック

🪟 対応OS

Windows 11（推奨）または Windows 10 (バージョン 2004 以降、ビルド 19041 以降)。64-bit版必須。

⚙️ CPU仮想化 (VT-x / AMD-V)

タスクマネージャーの「パフォーマンス」➔「CPU」で「仮想化: 有効」になっていることを確認してください（無効の場合はマザーボードBIOSでSVM/Intel VTをON）。

💾 必要メモリ

最小8GB、推奨16GB以上。RandomYデータセットの展開とHugePages用に約2.5GB〜3GBのRAMを消費します。

STEP 1

Windowsに WSL2 ＆ Ubuntu 24.04 を導入する

作業環境: PowerShell (管理者)
  1. Windowsの [スタートボタン] を右クリック して、[ターミナル（管理者）] または [PowerShell（管理者）] を開きます。
  2. 以下のコマンドをコピーして貼り付け、[Enter] キーを押します：
    PowerShell (管理者) 
    wsl --install -d Ubuntu-24.04
  3. ダウンロードと展開が完了したら、画面の指示に従って Windows PC を再起動 します。
  4. PC再起動後、自動的に Ubuntu 24.04 の黒いターミナル画面 が立ち上がります。
    ※ 開かない場合は、Windowsのスタートメニューから「Ubuntu 24.04」をクリックして起動してください。
  5. ターミナル上に Enter new UNIX username: と表示されたら、お好きなユーザー名（半角英小文字、例: miner）を入力して [Enter]。
    続けて New password: を求められるので、パスワードを入力します（※画面には伏字も出ませんが正しく入力されています）。
💡 すでにWSL2を使っている既存ユーザーの方へ
Ubuntuターミナルで lsb_release -a を実行し、Description: Ubuntu 24.04 LTS と表示されるか確認してください。
Ubuntu 20.04や22.04をお使いの場合は、PowerShell管理者から wsl --install -d Ubuntu-24.04 を実行すれば、既存環境を壊さずにUbuntu 24.04を並行追加インストールできます！
STEP 2

Ubuntu 24.04 の初期更新と必須ライブラリのインストール

作業環境: Ubuntu 24.04 (bash)

Ubuntuの黒いターミナル画面で、以下のコマンドを1行コピーして貼り付け、[Enter] を押します（途中でパスワードを聞かれたらSTEP 1で決めたパスワードを入力）：

Ubuntu 24.04 (bash) 
sudo apt update && sudo apt upgrade -y && sudo apt install -y wget tar curl libssl-dev hwloc libhwloc-dev tmux

※ これにより、ダウンローダー（wget/curl）、解凍ツール（tar）、暗号通信ライブラリ（libssl）、CPUトポロジー検出（hwloc）、およびバックグラウンド常駐ツール（tmux）がすべて整います。

STEP 3

【採掘速度20〜30%UP】HugePages（巨大ページ）を有効化する

超重要チューニング

Core Blockchainが採用するRandomY（PoDE）は、CPUキャッシュとメインメモリ間の超高速アクセスを要求します。
Linux標準の4KBページングではなく2MBのHugePages（巨大ページ）を割り当てておかないと、ハッシュレートが20%〜30%も低下します。必ず有効化してください！

① 今すぐHugePagesを割り当てる（即時反映）：
Ubuntu 24.04 (bash) 
sudo sysctl -w vm.nr_hugepages=1280
② PC再起動後も自動でHugePagesを有効に保つ（永続化）：
Ubuntu 24.04 (bash) 
echo "vm.nr_hugepages=1280" | sudo tee -a /etc/sysctl.conf
✅ 確認コマンド: grep Huge /proc/meminfo を実行して、HugePages_Total: 1280 と表示されれば完了です！
STEP 4

CoreMiner 最新版バイナリのダウンロード ＆ 展開

Catch That Rabbit 公式

専用フォルダを作成し、公式リポジトリから最新バイナリ（v0.19.89）をダウンロードして解凍・実行権限を付与します。
以下のコマンドをまとめてコピー＆ペーストして実行してください：

Ubuntu 24.04 (bash) - 一括ダウンロード＆展開 
mkdir -p ~/coreminer && cd ~/coreminer
wget https://github.com/catchthatrabbit/coreminer/releases/download/v0.19.89/coreminer-linux-x86_64.tar.gz
tar -zxvf coreminer-linux-x86_64.tar.gz
chmod +x coreminer
動作確認テスト：
Ubuntu 24.04 (bash) 
./coreminer --version

🎉 ターミナルに「coreminer version 0.19.89」と表示されれば、導入成功です！

画面を閉じても24時間動き続けるバックグラウンド実行（tmux）

STEP 7

Windowsが重くならないWSL2メモリ制限設定（.wslconfig）

PC快適性チューニング

WSL2はデフォルトでPC全体のメモリの半分以上を確保しようとするため、Windows側のブラウザや作業が重くなる場合があります。
Windows側の設定ファイル .wslconfig で上限を定めておくと、普段使いも極めて快適に維持できます。

  1. Windowsで Win + R を押し、notepad %USERPROFILE%\.wslconfig と入力して [OK] を押します。
  2. 新規作成を尋ねられたら [はい] を押し、以下の内容を貼り付けて保存します：
    C:\Users\<ユーザー名>\.wslconfig 
    [wsl2]
memory=8GB
processors=16
swap=0
    ※ メモリ上限（8GB等）と割り当てスレッド数はご自身のPCスペックに合わせて調整してください。
STEP 8

【絶対解決】つまずきやすいトラブルシューティング Q&A

Q1. 「version 'GLIBC_2.38' not found」というエラーが出て起動しない
A. 原因は古いUbuntu（20.04や22.04）です！
最新CoreMinerはUbuntu 24.04（GLIBC 2.38+）が必須です。PowerShell（管理者）を開き、wsl --install -d Ubuntu-24.04 を実行してUbuntu 24.04を導入し、スタートメニューから「Ubuntu 24.04」を開いてSTEP 2以降を実行してください。
Q2. 「Failed to allocate huge pages」と表示される
A. HugePagesが未設定または不足しています。
sudo sysctl -w vm.nr_hugepages=1280 を実行してください。それでも出る場合は、PC全体の使用中メモリが多く空きが足りない可能性があるため、一旦ブラウザ等の重いアプリを閉じてから再実行してください。
Q3. マイニングを開始したのに、プールやダッシュボードに反映されない
A. 反映までに約5〜15分の集計タイムラグがあります。
ターミナル上で [Stratum] Solution found! Accepted share という緑色の文字が出ていれば、ブロックチェーン上への提出は100%成功しています。プール側で一定数のシェアが集計されると、Web画面にワーカー名とハッシュレートが表示されます。
Q4. プールへの接続が「Connection refused / timeout」になる
A. 自宅ルーターのポート制限またはプールの一時的なメンテナンスです。
STEP 5のジェネレーターでプール先を「香港（hk.catchthatrabbit.com:8008）」または「フィンランド（fi.catchthatrabbit.com:8008）」に切り替えてお試しください。
