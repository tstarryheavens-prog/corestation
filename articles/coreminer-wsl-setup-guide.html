マイニング実践・導入ガイド

【完全初心者OK】Windows WSL2でCoreMinerを最速導入する完全手順マニュアル（Ubuntu 24.04必須・図解）

📅 公開日: 2026-09-18 ✍️ 執筆: リコロ (Ricolo) 🔒 監修: CoreStation 技術検証チーム
⚠️【最重要】CoreMiner最新版は「Ubuntu 24.04 LTS 以上」が必須です！

公式CoreMiner（v0.19.89等）は最新の標準ライブラリ（GLIBC 2.38以上）でコンパイルされています。
古い Ubuntu 20.04 や 22.04 LTS では、起動時に「version 'GLIBC_2.38' not found」という致命的エラーが出て絶対に起動しません。
WSL2をインストールする際は、必ず wsl --install -d Ubuntu-24.04 と指定してください！

1. はじめに：なぜ Windows ネイティブではなく WSL2 なのか？

Core Blockchainが採用するコンセンサスアルゴリズム「RandomY (PoDE)」は、CPUのL3キャッシュ帯域とメモリアクセス速度に極めて敏感です。WindowsのWin32バイナリと比較して、Linuxのネイティブ環境（glibc / pthreads）ではスレッドスケジューリングのオーバーヘッドが少なく、10%〜20%高いハッシュレートを記録します。

Windows Subsystem for Linux 2 (WSL2) を利用すれば、Windowsの日常利用を快適に保ちながら、中身は完全なLinuxカーネル上でCoreMinerを最高効率で稼働させることができます。

2. 全ステップ・完全導入ロードマップ

【STEP 1】Windows に WSL2 & Ubuntu 24.04 を導入

スタートボタンを右クリック ➔ 「ターミナル（管理者）」または「PowerShell（管理者）」を開き、以下を実行します：

wsl --install -d Ubuntu-24.04

完了後、PCを再起動すると自動的にUbuntu 24.04が起動します。任意のユーザー名とパスワードを設定してください。

【STEP 2】必須ライブラリの一括インストール

Ubuntuのターミナルで以下をコピペ実行します：

sudo apt update && sudo apt upgrade -y && sudo apt install -y wget tar curl libssl-dev hwloc libhwloc-dev tmux

【STEP 3】ハッシュレート20〜30%向上の必須技！「HugePages」有効化

Linux標準の4KBページングから2MB HugePagesに切り替えることで、メモリアクセスボトルネックを解消します：

# 即時適用
sudo sysctl -w vm.nr_hugepages=1280

# PC再起動後も有効に保つ設定
echo "vm.nr_hugepages=1280" | sudo tee -a /etc/sysctl.conf

※ 確認: grep Huge /proc/meminfo で HugePages_Total: 1280 となればOK！

【STEP 4】CoreMiner 最新版バイナリのダウンロード

作業フォルダを作成し、公式リポジトリからバイナリを取得して解凍します：

mkdir -p ~/coreminer && cd ~/coreminer
wget https://github.com/catchthatrabbit/coreminer/releases/download/v0.19.89/coreminer-linux-x86_64.tar.gz
tar -zxvf coreminer-linux-x86_64.tar.gz
chmod +x coreminer
./coreminer --version

【STEP 5】採掘起動コマンドの実行

ご自身のウォレットアドレスとワーカー名、スレッド数を指定して起動します：

./coreminer -P stratum+tcp://[あなたのウォレットアドレス].[ワーカー名]@sg.catchthatrabbit.com:8008 -t [スレッド数]
  • プール推奨: 日本国内からはシンガポール（sg.catchthatrabbit.com:8008）が最も低遅延です。
  • 推奨スレッド数: Ryzen 9 7950X: -t 30 / Core i9-14900: -t 16 / Core i5-13500: -t 11

【STEP 6】24時間連続稼働テクニック（tmux）

ターミナルを閉じてもマイニングを止めないために tmux を使用します：

tmux new -s miner
# ここでマイニング起動コマンドを実行
# 画面から離脱: [Ctrl] + [B] ➔ [D]
# 画面に復帰: tmux a -t miner

【STEP 7】Windowsが重くならないWSL2メモリ制限（.wslconfig）

Win + R ➔ notepad %USERPROFILE%\.wslconfig でファイルを作成し保存します：

[wsl2]
memory=8GB
processors=16
swap=0

3. よくあるエラーとトラブルシューティング

  • Q. GLIBC_2.38 not found と出る:
    ➔ Ubuntu 22.04以下の古いバージョンです。PowerShell管理者から wsl --install -d Ubuntu-24.04 をインストールしてUbuntu 24.04から実行してください。
  • Q. プールに反映されない:
    ➔ 初回シェアが採掘されてからプール集計・Web表示まで5〜15分かかります。ターミナルに Accepted share が出ていれば正常です。
