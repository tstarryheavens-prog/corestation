🎮 1. 自作PC＆オンラインゲームで例える「XCB」と「CTN」の決定的違い！

まずは結論から！この2つの違いを、自作PCやゲームの世界に例えてみましょう！

項目 ⛏️ XCB (Core Coin) 🎟️ CTN (Core Token)
分類 レイヤー1 ネイティブコイン（基幹資産） CBC-20 ユーティリティトークン（実用通貨）
自作PCで例えると PCケース・電源・マザーボード（マシンを動かす土台そのもの） Steamウォレット・各種ゲームキー（PC上で遊ぶためのコンテンツチケット）
MMORPGで例えると ダンジョンで採掘する「幻の鉱石」（世界に少しずつ供給される金） 街のギルドや市場で使える「共通ギル・ジェム」（取引や手数料に使う通貨）

主な役割 チェーン全体のセキュリティ担保、価値の保存 dApps利用料、CorePass認証、DeFi、取引所手数料

そうなんです！イーサリアムで例えるなら、XCBは「ETH」、CTNはエコシステム内で流通する「代表的なERC-20トークン（UNIやLINKのような存在）」と考えると一番しっくりきます！💡

⚙️ 2. CTNの基本スペック：なぜ「10億枚固定」でマイニングできないのか？

「えっ、CTNってマイニングで掘れないの！？」と思った方、大正解です！
CTNはマイニングマシンで掘り出すコインではなく、Core Blockchainのスマートコントラクト規格である「CBC-20」に基づいて発行されたトークンです。

  • トークン名称: Core Token (ティッカー: CTN)
  • トークン規格: CBC-20（Core Blockchain標準ファンジブルトークン）
  • 小数点桁数: 18 decimals
  • 最大供給量: 1,000,000,000 CTN（10億枚）

ビットコインやXCBのようなPoW/PoDEコインは、時間をかけて徐々に採掘されていきますよね。でも、日常的なサービス決済や取引所の手数料に使うトークンが「いつどれだけ採掘されるか分からない」「ガス代の急騰で使いづらい」となると、企業や一般ユーザーがWeb3アプリを使うハードルが跳ね上がってしまいます。

そこでCore Blockchainでは、「チェーンの安全を守る重厚な金庫番（XCB）」と、「高速・安価にサービスを循環させる決済エンジン（CTN）」を明確に切り分けるツイントークン・アーキテクチャを採用したのです！👏✨

📈 3. 過去の経緯と相場ヒストリー：なぜCTNは1円前後で安定している？

Core Blockchainがメインネットを稼働させた2022年以降、XCBとCTNはそれぞれ全く異なる価格特性を見せてきました。

  • XCBの価格動向: 半減期（発行減衰）や世界中のマイナーの参入・難易度急上昇の影響をダイレクトに受け、0.7円から一時は11円超までダイナミックに乱高下する「ボラティリティ型・投資資産」。
  • CTNの価格動向: 規制準拠取引所PingExchangeの稼働後、主に0.9円〜1.2円（約0.006〜0.008 USD）のレンジで非常に安定して推移する「ユーティリティ型・安定資産」。

🛠️ 4. エコシステムにおけるCTNの「4大活用シーン」

「具体的にCTNってどこで使うの？」という方のために、今すぐ使える＆これから使える4大ユースケースをまとめました！

① CorePass（分散型デジタルID）の認証・KYC利用料

スマホアプリ「CorePass」でパスポートや身分証を検証し、暗号化IDを発行する際の手数料や、認証連携サービス利用時のデポジットとしてCTNが使われます。

② PingExchangeでの取引手数料割引＆流動性ペア

分散型取引所PingExchangeにおいて、取引手数料をCTNで支払うと大幅割引を受けられるほか、XCB/CTN ペアがメインの基軸通貨ペアとして機能しています。

③ Wall Money（DeFi）でのステーキング＆レンディング

Core BlockchainネイティブのDeFiプラットフォーム「Wall Money」において、CTNを流動性プールにステーキングして利息（イールド）を獲得したり、レンディングの担保資産として活用できます。

④ スマートコントラクト・dApps実行の燃料

ブロックチェーン上でトークンを発行したり、分散型アプリケーション（dApps）を実行する際のサービスチャージとしてCTNが消費・循環されます。
